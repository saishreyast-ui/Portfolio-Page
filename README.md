# Portfolio Website

A personal portfolio website built as a front-end project to showcase my background, skills, projects, and contact information.

The project focuses on experimenting with layout, typography, navigation, animations, and interactive UI using HTML, CSS, Bootstrap, and JavaScript.

## Overview

This portfolio currently contains four main sections:

- **Home** — Landing page with navigation and social links.
- **About** — Personal introduction, academic timeline, and skills.
- **Projects** — Interactive project carousel with project descriptions.
- **Contact** — Interactive contact section with social and email details.

The website is currently a desktop-oriented first version. Responsive design and accessibility improvements are planned for a future version.

## Features

- Custom multi-page portfolio layout

## Running Locally

No build system or package manager is required.

Clone the repository:

```bash
git clone https://github.com/saishreyast-ui/Portfolio-Page.git
cd Portfolio-Page
```

Then open `index.html` in a browser.

## Deployment

The project is a static website and is deployed using GitHub Pages.

### GitHub Pages

1. Push the project to GitHub.
2. Open the repository on GitHub.
3. Go to **Settings → Pages**.
4. Select the branch containing the website.
5. Select the repository root (`/`) as the source directory.
6. Save the configuration.
7. GitHub Pages will provide the deployed website URL.

Because this is a static HTML/CSS/JavaScript project, no server-side runtime is required.
